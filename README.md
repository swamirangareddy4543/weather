# Weather App

A modern weather application built with **Kotlin**. This project provides real-time weather information with a clean and intuitive user interface.

## Features

- 🌤️ Real-time weather updates
- 📍 Location-based forecasts
- 🌡️ Temperature and weather condition display
- 💨 Wind speed and humidity information
- 🌅 Sunrise and sunset times
- 📱 Mobile-friendly design
- 🔄 Auto-refresh functionality

## Technologies Used

- **Language**: Kotlin
- **Platform**: Android (if mobile) / JVM (if desktop/backend)
- **Architecture**: Modern Kotlin best practices

## Getting Started

### Prerequisites

- Kotlin 1.8 or higher
- Gradle
- Android SDK (if building for Android)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/swamirangareddy4543/weather.git
cd weather
```

2. Build the project:
```bash
./gradlew build
```

3. Run the application:
```bash
./gradlew run
```
